# {{name}}

**{{n_total}} synthetic German higher-education materials**, one per topic, across all subjects of the German
higher-education subject classification. Each record contains a full text of about one A4 page together with a
title, a description, keywords, question-answer pairs, competence-oriented learning objectives and short search
queries derived from that text, plus educational metadata (subject, content type, target group, Bachelor/Master
level, teaching level).

The pairs can be used for tasks such as **full text → title, description, keywords, learning objectives** or
**search query → material**. All texts were generated by a large language model; none of
them is copied from existing educational materials.

It is the higher-education counterpart of
[synthetic-german-educational-materials-50k](https://huggingface.co/datasets/JanSchachtschabel/synthetic-german-educational-materials-50k),
which covers all education sectors with a smaller number of materials per sector. Both datasets share the same
column schema, so they can be combined; topics may overlap.

### Fields

| Field | Description |
|---|---|
| `id` | record ID |
| `education_sector` | always `higher_education` |
| `language` | language of the texts (`de`) |
| `fulltext` | generated full text in Markdown, typically 450–900 words (see lengths below) |

| `description` | description derived from the full text |
| `keywords` | 5–8 keywords derived from the full text |
| `qa_pairs` | question-answer pairs with `question`, `answer` and `type` (cognitive level after Bloom/Anderson, in German, e.g. `erinnern`, `verstehen`, `anwenden`) |
| `learning_objectives` | 1–4 competence-oriented learning objectives with `objective`, `operator` and `level` (Anderson/Krathwohl, in German); vague verbs such as „verstehen“ are not accepted as the final verb |
| `search_queries` | short search-box queries for which the material is a fitting hit (query → document pairs for retrieval) |
| `educational_context`, `_uri` | educational level (OpenEduHub vocabulary `educationalContext`) |
| `subject`, `_uri` | higher-education subject (Destatis subject classification, OpenEduHub vocabulary) |
| `content_type`, `_uri` | content type (OpenEduHub vocabulary `new_lrt`), e.g. lecture notes, exercise sheet, case study, explanatory video transcript |
| `content_type_check_match` | whether an independent check of the finished material detected the same content type |
| `target_group`, `_uri` | intended end user role (OpenEduHub vocabulary `intendedEndUserRole`) |
| `level`, `level_uri` | level, e.g. Bachelor or Master; URI from KIM `educationalLevel` or OpenEduHub `dqrCompetenceLevels`, empty where the level has no vocabulary value |
| `teaching_level` | teaching level of the topic (`grundlagen`, `vertiefung`, `forschung`) |
| `text_type`, `media_form` | text type and media form the full text was written as (e.g. text, slides, video or audio transcript) |
| `didactic_function`, `duration_minutes` | optional: didactic function and working time |
| `topic`, `topic_uri` | topic the material was generated from; URI only for topics from GND, OpenAlex and RVK |
| `topic_source` | where the topic comes from (see table above) |
| `rvk_notation` | class of the Regensburger Verbundklassifikation (RVK), for topics from RVK |
| `generator_model` | language model that generated the texts |
| `correction` | post-hoc correction of the record, if any: `regenerated`, `description`, `qa_pairs`, `search_queries` (see "How the data was created") |
| `description_previous` | earlier description, where the description was corrected afterwards |

Columns for other education sectors (`occupation`, `competence`, `curriculum`, `programme_area`, `digcomp_*`, …) are
kept for schema compatibility with the 50k dataset and are empty here; `title_previous` is empty as well.

Controlled values are given as labels together with their URIs, following the OpenEduHub / edu-sharing metadata
schema used by [WirLernenOnline](https://wirlernenonline.de).

## How the data was created

1. **Topics.** Higher-education topics were collected from several sources and assigned to the subjects of the
   Destatis classification:
   - *WirLernenOnline:* only topics (short subject headings) with their subject; no contents of WirLernenOnline
     records were used.
   - *OpenAlex* topics, *GND* subject headings frequently used for textbooks and theses in the hbz union catalogue,
     and thematic classes of the *Regensburger Verbundklassifikation* (RVK, levels 2–5).
   - *Subject profiles:* typical topics per subject written for this project.

   Assignments of topics to subjects were made by three independent LLM votes per topic, cross-checked with
   multilingual embeddings and existing crosswalks. Nearly identical topics within a subject (embedding similarity ≥ 0.97)
   were merged; one material was generated per remaining topic.
2. **Seeds.** Each seed combines one topic with metadata: subject, level, teaching level, content type, target group,
   text type and media form, plus optional controls such as didactic function and working time. Content types were
   rotated so that each fits the topic and level.
3. **Materials.** A language model ({{models}}, via the Anthropic Message Batches API) wrote the full text from the
   seed in the role of an author of higher-education materials. In separate calls it then derived title,
   description, keywords, learning objectives and search queries **only from the full text** and the fixed metadata,
   without seeing the seed's topic, so that the pairs reflect the task "text → metadata". Finally the content type
   was detected independently and question-answer pairs were generated from the full text.
4. **Validation.** Every output was checked (length, format, number of keywords, valid taxonomy levels) and
   requested again if unusable, up to three times per field. Titles and descriptions that named the material type or
   started with a stock phrase were requested again, but accepted on the last attempt; an overlong title was
   shortened to its main phrase on the last attempt. Materials that still failed were
   generated once more from the same seeds; in this second run a learning-objectives answer with a single valid
   objective and a content type stated in a full sentence were accepted. {{n_total}} of the seeds yielded a complete
   material; the remaining ones were dropped.{{title_note}}

Every record in the original data carries the source and method of each field; this export contains the fields
useful for training. Export date: {{export_date}}.

## Intended use

- Training and evaluating models that generate titles, descriptions, keywords and learning objectives for German
  higher-education resources.
- Training and evaluating retrieval models with the search queries (query → material).
- Question generation and question answering on educational texts.
- Research on metadata enrichment for open educational resources.

## Limitations

- **Synthetic texts.** The materials were not reviewed by subject experts and may contain factual errors. They are
  not intended to be used as learning materials.
- **Single model, single style.** All texts come from one language model and one set of prompts; real materials are
  more diverse in style, structure and quality.
- **Length.** Full texts are about one A4 page. Real lecture notes, slides or web pages are often longer and contain
  navigation or layout residue; preprocess them (cleaning, shortening) before applying a model trained on this data.
- **German context.** The texts are in German and refer to the German higher-education system.
- **Uneven coverage.** Topic sources differ in depth between subjects (for example, RVK is richer in some fields than in
  others), so some subjects are covered in more depth than others.
