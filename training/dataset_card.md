# {{name}}

**{{n_total}} synthetic German educational materials** covering all education sectors in Germany: school, higher
education, vocational education and training, adult education and early childhood education. Each record contains a
full text of about one A4 page together with a title, a description, keywords and question-answer pairs derived from
that text, plus educational metadata (educational level, subject, content type, target group).

The dataset was built to train small text-to-text models (for example mT5) that generate metadata for educational
resources from their full text: **full text → title, description, keywords**. All texts were generated by a large
language model; none of them is copied from existing educational materials.

## Dataset structure

{{split_table}}

Splits are assigned **by topic**: all materials generated from the same topic are in the same split, so test topics
are never seen during training.

### Fields

| Field | Description |
|---|---|
| `id` | record ID |
| `education_sector` | `school`, `higher_education`, `vocational`, `adult_education`, `early_childhood` |
| `language` | language of the texts (`de`) |
| `fulltext` | generated full text in Markdown, about 400–550 words |
| `title` | title derived from the full text (10–120 characters) |
| `description` | description derived from the full text (250–1,200 characters) |
| `keywords` | 4–8 keywords derived from the full text |
| `qa_pairs` | at least 8 question-answer pairs with `question`, `answer` and `type` (cognitive level after Bloom/Anderson, in German, e.g. `erinnern`, `verstehen`, `anwenden`) |
| `educational_context`, `_uri` | educational level (OpenEduHub vocabulary `educationalContext`) |
| `subject`, `_uri` | school subject, higher-education subject, occupational group (KldB 2010) or adult-education subject area, depending on the sector |
| `content_type`, `_uri` | content type (OpenEduHub vocabulary `new_lrt`), e.g. worksheet, explanatory video transcript, case study |
| `content_type_check_match` | whether an independent check of the finished material detected the same content type |
| `target_group`, `_uri` | intended end user role (OpenEduHub vocabulary `intendedEndUserRole`) |
| `level` | level, e.g. school year group, Bachelor/Master, DQR level |
| `text_type`, `media_form` | text type and media form the full text was written as (e.g. text, slides, video or audio transcript) |
| `didactic_function`, `duration_minutes` | optional: didactic function and working time |
| `topic`, `topic_uri` | topic the material was generated from (GND, OpenEduHub topic trees, ESCO or OpenAlex), empty for topics from sources that are not openly licensed |
| `generator_model` | language model that generated the texts |

Controlled values are given as labels together with their URIs, following the OpenEduHub / edu-sharing metadata
schema used by [WirLernenOnline](https://wirlernenonline.de).

## How the data was created

1. **Topics and subjects from open vocabularies.** For each education sector, topics were collected from openly
   licensed sources and assigned to the subjects of that sector:
   - *School:* topic trees of the WirLernenOnline subject portals (OpenEduHub `oehTopics`) and further topics from
     keywords of WirLernenOnline records, matched to GND subject headings; school levels primary, lower and upper
     secondary.
   - *Higher education:* OpenAlex topics and GND subject headings frequently used for textbooks and theses in the hbz
     union catalogue, assigned to the Destatis subject classification.
   - *Vocational education and training:* combinations of ESCO occupations and their skills, occupational groups after
     KldB 2010, learning fields of vocational school framework curricula.
   - *Adult education:* GND course topics and basic education topics, organised by the subject areas of the
     German adult education centre statistics (DIE).
   - *Early childhood education:* GND topics for day-care centres, assigned to the seven educational areas of the
     joint framework of the German Länder.

   Assignments of topics to subjects, levels and sectors were made by three independent LLM votes per topic, cross-checked
   with multilingual embeddings and existing crosswalks; uncertain cases were reviewed editorially.
2. **Seeds.** Each seed combines one topic with metadata: educational level, subject, content type, target group and
   level, plus optional controls such as didactic function, working time, social form or competence level. Topics were
   distributed evenly; content types were rotated so that each fits the topic and level.
3. **Materials.** A language model ({{models}}) wrote the full text from the seed in the role of an author of
   educational materials. In separate calls it then derived title, description and keywords **only from the full text**
   and the fixed metadata, without seeing the seed's topic or keywords, so that the pairs reflect the task
   "text → metadata". Outputs were validated (length, number of keywords) and requested again if unusable. Finally
   the content type was detected independently and question-answer pairs were generated from the full text.

Every record in the original data carries the source and method of each field; this export contains the fields
useful for training. Export date: {{export_date}}.

## Intended use

- Training and evaluating models that generate titles, descriptions and keywords for German educational resources.
- Question generation and question answering on educational texts.
- Research on metadata enrichment for open educational resources.

## Limitations

- **Synthetic texts.** The materials were not reviewed by subject experts and may contain factual errors. They are
  not intended to be used as learning materials.
- **Single model, single style.** All texts come from one language model and one set of prompts; real materials are
  more diverse in style, structure and quality.
- **Length.** Full texts are about one A4 page. Real web pages or worksheets are often longer and contain navigation
  or layout residue; preprocess them (cleaning, shortening) before applying a model trained on this data.
- **German context.** The texts are in German and refer to the German education system.
- **Uneven coverage.** Topic sources differ in depth between subjects and sectors.
